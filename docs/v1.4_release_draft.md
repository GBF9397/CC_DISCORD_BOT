## 公告

```markdown
# 🤖 Gemma 4 机器人 v1.4 更新

## ⌨️ 指令一行就能用，任何频道都行
- 用 `!` 或中文键盘的 `！` 开头发一行就行，复制粘贴的 `/draw ...` 也认
- 不用只在 #gemma-4，任何频道都能用
- 示例：`!draw ganyu`、`!status`

## 🎨 改图：/refine
- 只改你自己的上一张图，几个人同时改图互不影响
- 只写要改的地方，没提到的部分保持不变，可以一轮一轮改下去
- 示例：`!draw ganyu` → `!refine 要史诗一点` → `!refine 我要正脸`

## ↩️ 撤回：/recall
- 不喜欢最新那张？`!recall` 撤回它，回到上一张
- 撤回后再 `!refine`，会换一个新的结果，不会又画回刚才那张

## 🖼️ 上传图改图：/edit
- 发图时写 `!edit 改动`，或用 `/edit`
- 构图和姿势保留，只改你说的地方；换发色这种大改动也能保住角色的样子
- 示例：上传甘雨的图 + `/edit 把头发改成红色` → 红发甘雨，角和姿势不变

## 👗 换角色
- 第 1 张放衣服/姿势，后面最多再放 3 张同一个角色的图
- 机器人把那个角色换进第 1 张：衣服、姿势、背景不变
- 示例：女仆图 + 两张甘雨 + `!edit 第2和第3张的角色穿第1张的衣服` → 穿女仆装的甘雨

## 🔒 私人画图：!dmdraw、!dmedit、!dmrefine、!dmrecall
- 跟普通画图一样，但你的请求会被隐藏，画好的图只私信给你
- 频道只显示「画画中（私人请求）」，不显示是谁
- 私人图有自己的记录，`!dmrefine` 改、`!dmrecall` 撤回
- 示例：`!dmdraw 一只猫`

## ⏱️ 画图更好等
- 排队时显示预计还要多久（例如 ⏱️ 预计 2 分 30 秒）
- 写提示词时有倒数，画图时有进度条
- 大图上传也不会卡住了

## 📷 写实风格
- 开头写 realistic 就画写实照片风，动漫角色会画成真人 cos
- 示例：`!draw realistic 一个女生`

## 📊 投票：/poll
- 一行版：`!poll 问题 | 选项 | @人`
- 选项用 `，` `|` `/` `、` 隔开，最多 10 个；不填就是「是/不是」
- @了人：会提醒他们，全员投完自动结束（最多 7 天）；没 @ 人开 1 天
- 发起人可以按「结束投票」，机器人会贴出目前票数
- 示例：`/poll question:你们觉得谁最帅 options:ey, gib, ep, hung, xuan, hh, jk` → 7 个选项的投票

## 📅 活动：!event
- 最简单：只发 `!event`，点「创建活动」，填名称和地点，再从菜单选日期、时间、时长
- 一行版：`!event 名称 | 日期 | 时间 | 地点`，顺序可以乱，时间可写 20:30、8pm、晚上8:30
- 点活动卡片上的「感兴趣」🔔，开始时 Discord 会通知你
- 建活动的人可以按「结束活动」
- 示例：`!event 电影夜 | 10-10 | 8:30pm | 语音频道` → 10 月 10 日 8:30 PM 的活动卡片

## 🖥️ 电脑负载：/status、!status
- 进度条显示显卡、显存、CPU、内存，每 3 秒刷新，持续 1 分钟
- `/status` 只有你看得到；`!status` 大家都看得到；画图时也能用

## 💬 不想让机器人插嘴：!comment
- 消息以 `!comment` 开头，机器人不回也不记
- 你的话会以你的名字和头像重新发出来，看起来就像普通聊天
- 用法：`!comment 你们先聊，我去吃饭`

## 🎭 角色扮演优化
- 人设优化了，角色更像本人
- 用法：`/persona character 角色 作品`，例如 `/persona character 芙宁娜 原神`
- 之前设过的角色，要重新设一次

## 🔧 修复
- 回复不再被硬切成「…」
- 机器人表情少写冒号时也能正常显示
```

## 指令列表（v1.4 完整）

```markdown
# 🤖 Gemma 4 机器人 指令列表（v1.4）

带 `!` 的指令在任何频道都能用（`！` 或粘贴的 `/` 也行）。

## 💬 聊天
- 在 #gemma-4 直接发消息，或在任何频道 @机器人
- `/ask` 或 `!ask 问题`：问机器人，例 `!ask 今天吃什么好`
- 发图片：机器人会看图回答
- `/search` 或 `!search 问题`：先上网查再回答，例 `!search 今天天气`
- `/comment` 或 `!comment 文字`：机器人不回也不记，例 `!comment 我去吃饭`
- `/reset` 或 `!reset`：清空本频道记忆（只记最近 30 条）

## 🎭 人设
- `/persona`：看当前人设
- `/persona preset`：现成人设（buddy、tsundere、wuxia、pirate、roast）
- `/persona custom 描述`：自己写人设
- `/persona character 角色 作品`：例 `/persona character 芙宁娜 原神`

## 🎨 画图（画图时机器人暂停聊天，排队先来先画，每人一次排一张）
- `/draw` 或 `!draw 描述`：例 `!draw ganyu`、`!draw realistic 一个女生`
- `/refine` 或 `!refine 改动`：改你的上一张图，例 `!refine 我要正脸`
- `/recall` 或 `!recall`：撤回最新一张，回到上一张
- `/edit` 或 发图 + `!edit 改动`：改上传的图，例 `!edit 把头发改成红色`
- 换角色：第 1 张 + 最多 3 张角色图，例 `!edit 第2和第3张的角色穿第1张的衣服`
- `/drawstyle` 或 `!style anime|realistic`：切换本频道画风，例 `!style realistic`

## 🔒 私人画图（图只私信给你，请求会被隐藏）
- `/dmdraw` 或 `!dmdraw 描述`：例 `!dmdraw 一只猫`
- `/dmedit` 或 发图 + `!dmedit 改动`
- `/dmrefine` 或 `!dmrefine 改动`：改你最近一张私人图
- `/dmrecall` 或 `!dmrecall`：撤回最新一张私人图

## 🛠️ 工具
- `/poll` 或 `!poll 问题 | 选项 | @人`：例 `!poll 今晚吃什么 | 炒饭，煎蛋`
- `/event` 或 `!event`：弹出表单；或一行 `!event 电影夜 | 10-10 | 8:30pm | 语音频道`
- `/status` 或 `!status`：看电脑负载（`/status` 只有自己看得到）

🔒 聊天、图片和画好的图都不会存在电脑上，重启后记忆和人设清空。
```
